# Changelog

All notable user-facing changes are recorded here. Technical decisions belong in
[ADRs](docs/adr/README.md).

## Unreleased

### Documentation

- Added project overview, AI specification, AI implementation plan, contribution rules, roadmap,
  status tracking, release process, operations runbook, security policy, and requirements
  traceability.
- Added GitHub issue and pull request templates.

### Current product state

- Landmark catalog and nearby PostGIS search are available.
- Vision Camera AR currently provides frame telemetry and demonstration landmark selection.
- Groq AI-guide backend endpoint exists.
- Landmark photo upload and deletion use private S3 and CloudFront URLs.
- Full visual landmark recognition is not yet implemented.

## Release format

Use [Keep a Changelog](https://keepachangelog.com/) categories such as Added, Changed, Fixed,
Removed, and Security. Release entries should link to the relevant pull requests.
