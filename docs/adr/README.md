# Architecture Decision Records

ADRs explain decisions that affect future implementation. They are append-only: supersede an old
decision with a new ADR instead of silently rewriting history.

## Format

Each ADR contains:

- status: Proposed, Accepted, Superseded, or Rejected;
- context;
- decision;
- consequences;
- alternatives considered.
